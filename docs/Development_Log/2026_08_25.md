## Decisions Made

* Four M3 fasteners will be used to secure the faceplate to the main body
* The body will use 8 mm bosses with 2.6 mm pilot holes, while the faceplate will use 3.4 mm clearance holes
* Goal 2 is considered complete following alignment, interference, and display-fit verification
* The original button meshes will remain reference components rather than being converted into production solids
* Button openings will be based on the narrow pass-through stems, not the exterior caps or retaining flanges
* A nominal radial clearance of 0.30 mm will be used around the button stems
* Minor asymmetry in the triangular opening is acceptable because it follows the original mesh geometry and remains hidden beneath the button cap
* Visual clearance verification is acceptable for the mesh buttons because Fusion 360 cannot reliably include the linked mesh components in normal interference checks
* Goal 3 will remain in progress until the remaining front-panel slot and lower port openings are completed

## Problems/Blockers

* The mounting bosses initially passed through the enclosure because the extrusion accidentally referenced `BodyDepth` rather than `BossDepth`
* Linked button meshes could not be selected using Create Mesh Section Sketch
* Fusion 360 did not provide an Edit in Place option for the linked mesh components
* Temporary local mesh copies were required to generate the button section profiles
* The first circular section measurements captured the retaining flanges instead of the narrower button stems
* The triangular mesh produced a slightly asymmetric fitted profile
* Normal interference checks could not be performed between the faceplate and the linked mesh buttons
* Final physical fit will still depend on real 3D-printing tolerances
