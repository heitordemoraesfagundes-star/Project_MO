# Project MO — Development Log

**Date:** 2026-08-23
**Session:** Enclosure Analysis & Component Fit Verification

## Objectives

* Correct the scale of the original enclosure files
* Determine whether the original enclosure can accommodate the essential V1 components
* Avoid unnecessary enclosure modifications
* Establish preliminary positions for the main internal modules

## Work Completed

* Confirmed that the original STL files were imported at an incorrect scale
* Corrected the enclosure parts using a uniform scale factor of 100
* Repaired the front plate mesh using the Close Holes operation
* Tested multiple mesh-to-solid conversion methods
* Identified geometry distortion and fragmentation caused by complete mesh conversion
* Created DL-009: Enclosure Analysis & Modification Strategy
* Reviewed the BOM and reduced the active V1 scope to the essential components
* Retained all original buttons and the D-pad to avoid unnecessary front-panel modifications
* Created simplified CAD envelopes for:

  * ESP32 DevKit
  * Display
  * Speaker
  * MAX98357A amplifier
  * USB connector and cable clearance
* Identified the original display as a 5-inch, 800 × 480 DSI module
* Confirmed that the original DSI display is not directly compatible with the ESP32
* Evaluated 5-inch ESP32-compatible display alternatives
* Rejected the Nextion NX8048T050 because its 133.5 mm width was too large for the enclosure
* Identified a compact 5-inch BuyDisplay RA8875 SPI display as the leading candidate
* Confirmed that the BuyDisplay envelope fits the original screen compartment
* Positioned the ESP32 near the existing USB opening
* Corrected the USB-clearance model to distinguish the connector tip from the external plug housing
* Confirmed that the existing USB opening can accommodate the connector
* Positioned a 40 mm speaker near the original sound openings
* Positioned the amplifier vertically beside the speaker without blocking the ventilation slots
* Confirmed that the original enclosure appears large enough for the essential V1 modules

## Decisions Made

* The original STL files will be used primarily as dimensional references rather than fully converted into editable solids
* Complete enclosure remodeling will be avoided unless a verified component conflict requires it
* Component fit will be tested before designing brackets or modifying enclosure parts
* All original button positions will be preserved for V1
* The 5-inch BuyDisplay RA8875 SPI display will remain the leading display candidate pending final technical and supplier verification
* The existing USB opening will be used for ESP32 programming and power access
* A 40 mm speaker will be used instead of the larger clearance envelope originally modeled
* The amplifier will be mounted vertically beside the speaker to preserve airflow
* The original enclosure is provisionally considered sufficient for the V1 hardware

## Problems/Blockers

* The original STL files contained incorrect scale values
* The front plate mesh contained open, unoriented, and disconnected geometry
* Prismatic conversion produced incomplete and fragmented bodies
* Faceted conversion distorted some curved corner regions
* Fusion could not perform normal solid interference checks against the mesh enclosure
* The exact BuyDisplay configuration, controller-board layout, power requirements, and delivered cost have not yet been confirmed
* The final 5 V power-distribution design remains incomplete

## Next Steps

* Confirm the exact BuyDisplay RA8875 model and configuration
* Determine the total V1 power requirements
* Select an appropriate regulated 5 V power supply
* Plan cable routes between the display, ESP32, amplifier, and speaker
* Verify whether the original button files include tactile-switch holders
* Determine which components require brackets, standoffs, or mounting tape
* Perform a final enclosure-closure check before designing mounting parts
