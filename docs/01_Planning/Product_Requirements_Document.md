# Product Requirements Document (PRD)

## 1. Project Overview

The objective of this project is to design and build an interactive robot prototype inspired by the character BMO from the series *Adventure Time*.

## 2. Motivation

Explore the process of transforming a fictional concept into a functional engineering system through iterative design, prototyping, and problem-solving.

## 3. Main Objectives

### 3.1 Design

- Develop an appropriate physical structure and design inspired by the character.
- Create an adapted 3D model.
- Allow assembly and internal maintenance.

### 3.2 Electronics

- Implement a functioning main controller.
- Implement a lighting system.
- Implement an audio system.
- Implement interactive buttons.
- Implement basic sensors for movement and voice.

### 3.3 Programming

- Develop dedicated project code.
- Implement component control.
- Implement a simple programmed response system.

## 4. Functional Requirements

### FR-01 — Visual Interaction

The robot must have a visual interface capable of displaying a diverse range of emotions.

### FR-02 — User Input

The robot must be interactive. Possible interactions include buttons for changing emotions or states, voice commands, or visual commands.

### FR-03 — Audio Output

The robot must be able to reproduce simple sounds and pre-recorded phrases.

## 5. Non-Functional Requirements and Limitations
