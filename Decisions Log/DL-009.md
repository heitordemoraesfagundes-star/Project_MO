# DL-009 — Enclosure Analysis & Modification Strategy

**Date:** 2026-08-23
**Status:** Accepted

---

## 1. Decision

Project MO will use a **fit-first and selective remodeling strategy** for the existing 3D enclosure model.

The original STL files will initially be used as dimensional and visual references. Simplified models representing the maximum dimensions of the main electronic modules will be positioned inside the enclosure to verify component fit before any part is modified.

If changes are required, only the affected parts will be remodeled or replaced with simplified parametric versions created directly in Fusion 360.

---

## 2. Context

The original enclosure files were provided as STL meshes and presented incorrect scale values when imported into Fusion 360. After correcting the scale, additional mesh problems were identified, including open geometry, inconsistent orientation, disconnected regions, and a high triangle count.

Attempts to repair and convert the front plate into an editable solid produced incomplete geometry, multiple disconnected bodies, and inaccurate curved corners.

Because it has not yet been confirmed that the selected V1 components require major enclosure modifications, converting and repairing every original STL could consume significant development time without providing a necessary functional benefit.

---

## 3. Alternatives Considered

| Option                                          | Advantages                                                                     | Disadvantages                                                                   |
| ----------------------------------------------- | ------------------------------------------------------------------------------ | ------------------------------------------------------------------------------- |
| **Fit-first and selective remodeling**          | Reduces unnecessary CAD work; preserves usable original parts; requirement-led | Requires simplified component models and internal fit analysis                  |
| **Convert and modify every original STL**       | Attempts to preserve the complete original geometry in editable form           | Produces complex, fragmented, or inaccurate solids; time-consuming              |
| **Remodel the complete enclosure immediately**  | Produces clean and fully parametric geometry                                   | Requires substantial work before confirming that major modifications are needed |
| **Use the original enclosure without analysis** | Fastest initial approach                                                       | Creates a high risk of component interference after printing                    |

---

## 4. Rationale

The fit-first strategy was selected because enclosure modifications should be based on verified component requirements rather than assumptions.

Creating simplified component envelopes will allow the available internal space, clearances, mounting positions, cable paths, and access requirements to be evaluated before committing to major CAD work.

If the original enclosure provides sufficient space, it can be preserved and complemented with separate brackets, spacers, trays, or adapters. If a conflict is identified, only the affected part will be recreated as a simplified parametric model using the original STL as a dimensional reference.

This approach supports the Project MO design principles of simplicity, modularity, accessibility, and efficient development.

---

## 5. Consequences

### Positive

* Reduces time spent repairing and converting complex STL meshes.
* Avoids unnecessary modifications to usable enclosure parts.
* Allows component compatibility to be evaluated before printing.
* Ensures that modifications are supported by identified functional requirements.
* Produces cleaner and more manageable CAD files for newly modeled parts.
* Allows separate mounting components to be designed without rebuilding the complete enclosure.

### Trade-offs

* Simplified models must be created for the main V1 components.
* Some internal measurements may require mesh sections or reference sketches.
* The complete enclosure may still need to be remodeled if major component conflicts are identified.
* Original STL parts may remain difficult to edit directly.
