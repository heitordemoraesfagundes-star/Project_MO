# DL-001 — Project Scope and V1 Definitions

**Date:** 2026-07-31  
**Status:** Accepted

---

## 1. Decision

Project MO is an interactive stationary robot focused on user input and personality

---

## 2. Context

Project MO aims to be a simple project focused on the interaction between the robot and the user, so adding movement to it would simply complicate the design without contributing much to the project's goal

---

## 3. Alternatives Considered

| Option | Advantages | Disadvantages |
|---|---|---|
| **Stationary** | [Simple] | [Limited] |
| **Moving** | [Ample] | [Complex] |

---

## 4. Rationale

A stationary design is preferred for it´s simplicity and overall lower cost compared to a moving design

---

## 5. Consequences

**Benefits:** Cheaper and easier to work

**Trade-offs:** More limitaions and smaller scope
