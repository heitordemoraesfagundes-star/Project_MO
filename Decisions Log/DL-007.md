# DL-007 — Mechanical & Enclosure Design

**Date:** 2026-08-06
**Status:** Accepted

---

## 1. Decision

Project MO V1 will use a **3D-printed custom enclosure** based on the project's original visual inspiration, with modifications made to accommodate the selected electronics and internal components.

The enclosure will prioritize functionality, accessibility, and integration of the hardware while maintaining MO's intended visual identity.

Autodesk Fusion was selected as the primary CAD software for modifying Project MO's 3D-printed components.

---

## 2. Context

The initial concept for MO was inspired by an existing small robot design. However, directly reproducing the original design would not guarantee compatibility with the electronics selected for Project MO.


The enclosure therefore needed to be adapted to provide appropriate space for the components, mounting points, wiring, and access to required interfaces.

The original models are provided in STL format, requiring mesh handling as well as precise mechanical modifications for component mounting, cable routing, and enclosure integration.


---

## 3. Alternatives Considered

| Option                                           | Advantages                                                                        | Disadvantages                                          |
| ------------------------------------------------ | --------------------------------------------------------------------------------- | ------------------------------------------------------ |
| **Custom-modified 3D-printed enclosure**         | Adaptable; relatively low cost; integrates with selected hardware; easy to revise | Requires CAD modifications and 3D printing             |
| **Use the original model without modifications** | Faster initial implementation; preserves original design                          | May not accommodate the selected electronics or wiring |
| **Fully custom enclosure from scratch**          | Maximum design freedom and hardware integration                                   | Greater CAD development time and complexity            |

---

## 4. Rationale

A modified 3D-printed enclosure was selected because it provides the best balance between **design flexibility, development time, cost, and hardware integration**.

Using the existing design as a starting point reduces unnecessary CAD work while still allowing the enclosure to be adapted specifically for Project MO.

This approach also allows future versions of the enclosure to be redesigned as the hardware evolves.

Fusion provides a good balance between mesh handling and precise mechanical CAD, while also being useful for future engineering work beyond MO V1.

---

## 5. Consequences

### Positive

* Provides dedicated space for MO's electronics.
* Allows component placement to be considered during mechanical design.
* Reduces unnecessary CAD development time.
* Makes future physical modifications relatively straightforward.
* Preserves the visual concept that inspired Project MO.

### Trade-offs

* The original model requires modifications before final printing.
* The physical design is constrained by the selected electronics.
* Additional iterations may be required after assembly and testing.
